# Fiscal Runtime Security Boundaries

- No raw tax returns, bank statements, invoices, addresses, account numbers, private keys, credentials or certificates are committed to this repository.
- Domain code operates on stable IDs and evidence references.
- Runtime event payloads may contain structured facts in deployed systems, but persistence adapters must enforce sensitivity classes and redaction policy.
- Official authority evidence and primary financial statements are classification inputs; they are not automatically copied into Git.
- Tool adapters must expose read/write capability and permission state through L14 Tool Graph.
- Legal truth promotion remains evidence- and policy-gated.
