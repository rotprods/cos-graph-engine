## Repairs actually implemented

### Memory — `packages/memory/src/memory-manager.ts`

Own/unref the housekeeping timer and expose idempotent disposal without clearing data. Reconcile layer/tag indexes on replacement, update, deletion and layer clearing. Preserve explicit null TTL; expire entries consistently for queries/stats. Keep consolidation changes inside the store update boundary. Retain existing serialized cross-links and reject malformed link metadata instead of silently overwriting it. Reject mutation of indexed entry identity.

Tests: `scripts/test-memory-regressions.cjs`, 10 checks including a separate natural-exit subprocess. No forced-success process exit was added.

### Authentication — `packages/api/src/auth.ts`, `packages/api/src/http-server.ts`

Replace payload-only JWT acceptance with HS256 HMAC verification using Node crypto and constant-time digest comparison. Enforce algorithm, issuer, audience, expiry, issuance/not-before, subject and role/permission contracts. Remove the identity cache that bypassed expiry and rotation. Reject placeholder/short signing keys for issuance. Deny anonymous capabilities; authorize routes before reading bodies or invoking services. Restrict configuration/token issuance to administrators and redact credential-bearing configuration keys.

Tests: `scripts/test-auth-boundary.cjs`, 35 checks. Tests include independently computed signatures, rejected tampering and privilege escalation, expiry/rotation rechecks, denial before effects, allowed administrator issuance and public health compatibility.

The old issuer placed the signing secret inside a base64 token component. Any real deployment using it needs an exposure assessment and authorized credential rotation. No deployed compromise is asserted. Legacy insecure tokens are intentionally invalidated; do not restore acceptance for compatibility.

The HTTP edit was restricted to two unique anchors against exact source blob `75ff084d5cd2965624d77a52a23545a0271163ee`. Its one-shot writer ran mandatory checks before committing and removed itself.

### Configuration — `packages/infrastructure/src/config.ts`

Honor declared schema.env bindings before they are masked by defaults. Generic unbound settings retain their mapping. Apply typed declared bindings in a second deterministic pass so they win over generic spellings independently of environment iteration order. Preserve defaults < environment < file < runtime priority. Do not add a competing configuration store.

Tests: `scripts/test-config-bindings.cjs`, 15 checks including actual JWT/API-key operation using environment configuration.
