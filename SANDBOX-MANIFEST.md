# SANDBOX MANIFEST

This sandbox is **only** for code generation.

GitHub is the source of truth for all code.

All verification happens on the user's local Mac with Claude Code (GPU, RAM, WebGL).

## Agent Rules:

*   **CREATE** code in the sandbox.
*   **PUSH** to GitHub immediately.
*   **DON'T** run complex builds here.
*   **DON'T** do visual debugging here.
*   **LEAVE** issues documented for Mac.

## Workflow:

```
Higgsfield
    ↓
GitHub
    ↓
Mac Local
```

This is binding for all agents.
